系統簡介

前端以 React.js 製作表單，資料送至 Spring Boot 後端，先暫存於 Redis 進行信箱驗證。
驗證通過後，資料與學生證影像儲存至 MongoDB。管理員可人工審核並批准會員。
批准後系統自動產生會員編號與電子會員卡（HTML/PDF），並寄送至會員信箱。
